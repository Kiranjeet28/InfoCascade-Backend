STUDENT ENDPOINTS (Protected by JWT):
  1. POST /api/notifications/register-token
     - Register device push token
     - Body: { token, deviceType, deviceName }

  2. POST /api/notifications/send-test
     - Send test notification to self
     - Body: { title, body }

  3. GET /api/notifications/history
     - Get notification history with pagination
     - Query: ?limit=20&skip=0

  4. PUT /api/notifications/:notificationId/read
     - Mark notification as read
     - Params: notificationId

ADMIN ENDPOINTS (Protected by JWT + Admin Role):
  5. POST /api/notifications/send-to-student
     - Send notification to specific student
     - Body: { studentId, title, body, notificationType, data }

  6. POST /api/notifications/send-bulk
     - Send notification to multiple students
     - Body: { studentIds[], title, body, notificationType, data }
